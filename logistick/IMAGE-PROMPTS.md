# Промпты для генерации изображений — Наша компания

Когда изображения будут готовы, поместите их в папку `images/` и замените контейнеры.
Для каждого слота укажите `data-slot` из таблицы ниже.

## Как добавить картинку

```html
<!-- Пример: заменить placeholder в hero-блоке -->
<div class="image-slot image-slot--hero has-image" data-slot="hero">
  <img src="images/hero.jpg" alt="Логистика — Наша компания">
</div>
```

## Рекомендации по стилю

- **Палитра:** тёмно-синий `#1a3a6b`, голубой `#0ea5e9`, белый, серый
- **Настроение:** профессионализм, надёжность, технологичность
- **Без текста** на изображениях — весь текст на сайте
- **Единый стиль** — все 7 изображений в одной визуальной гамме
